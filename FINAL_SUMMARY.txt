🔧 QUIZSERVICE API
═══════════════════════════════════════════════════════════════════════════════

QUIZ MANAGEMENT:
─────────────────
✅ quizService.saveQuiz(quiz)
   → Save new quiz to localStorage

✅ quizService.getAllQuizzes()
   → Get all quizzes

✅ quizService.getQuizById(id)
   → Get specific quiz

✅ quizService.deleteQuiz(id)
   → Remove quiz

ATTEMPT MANAGEMENT:
────────────────────
✅ quizService.saveQuizAttempt(quizId, studentId, answers, score)
   → Save student attempt

✅ quizService.getStudentAttempts(quizId, studentId)
   → Get attempts for a quiz

SCORING & SHUFFLING:
──────────────────────
✅ quizService.calculateScore(quiz, answers)
   → Compute score { correctCount, totalCount, percentage }

✅ quizService.shuffleQuizForStudent(quiz, studentId)
   → Create shuffled copy with deterministic shuffle per student

UTILITIES:
───────────
✅ quizService.generateId()
   → Generate unique quiz ID

✅ quizService.clearAllQuizzes()
   → Reset all data (for testing)

🔀 SHUFFLE ALGORITHM
═══════════════════════════════════════════════════════════════════════════════

APPROACH: Deterministic Per Student
─────────────────────────────────────
1. Extract student ID as seed
2. Use seed + question index to shuffle options array
3. Same student always gets same shuffle
4. Different students get different shuffles
5. Correct answer index is adjusted accordingly

IMPLEMENTATION:
─────────────────
const seed = parseInt(studentId.replace(/\D/g, "") || "0") % 1000;
// Uses seed + question index for deterministic shuffle
// Creates mapping from old indices to new positions
// Adjusts correctAnswer index in new position

BENEFITS:
──────────
✅ Prevents cheating by copying answers
✅ Fair for all students
✅ Consistent experience per student
✅ No need for backend shuffle storage
