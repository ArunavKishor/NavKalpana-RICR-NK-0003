## Slide 2: Problem Statement
- **Current Challenges:** Fragmented manual attendance, delayed assessment tracking, and lack of visual growth metrics for students.
- **The Solution:** A unified platform that centralizes institunional workflows and provides data-driven insights into student performance.
- **Goal:** Empower educators with automation and provide students with a clear path to improvement.

---

## Slide 3: Core Features (Admin)
- **Institution-wide Management:** Monitor all batches, students, and teachers from a single pane.
- **Resource Allocation:** Dynamic batch scheduling and instructor assignment.
- **System Integrity:** Secure role-based access control (RBAC) and audit trails for management.

---

## Slide 4: Core Features (Teacher)
- **Attendance 2.0:** Secure marking with a 10-minute edit lock and same-day validation.
- **Assessment Lifecycle:** Create, distribute, and grade assignments/exams with support for multi-format uploads (PDF/Images).
- **Batch Analytics:** Real-time distribution charts and module-wise progress tracking.
- **Doubt Resolution:** Direct student-teacher communication with priority handling.

---

## Slide 5: Core Features (Student)
- **Personalized Dashboard:** Track enrollment history, upcoming deadlines, and academic stats.
- **Academic Progress (OGI):** View the **Overall Growth Index** trend — a weighted metric balancing attendance and grades.
- **Attendance Transparency:** Interactive calendar showing daily status (Present/Absent/Late).

---

## Slide 6: Technology Stack
- **Frontend:** React 19, Vite, Tailwind CSS 4, Framer Motion (Animations), Recharts (Data Viz).
- **Backend:** Node.js, Express 5, JWT Authentication.
- **Database:** MongoDB Atlas (Cloud Database).
- **Cloud Storage:** Cloudinary (Profile photos and assignment files).

---

## Slide 7: Technical Architecture
- **MERN Architecture:** Decoupled Frontend and Backend communicating via REST APIs.
- **State Management:** React Context API for authentication state.
- **Security:** Bcrypt for password hashing and JSON Web Tokens (JWT) for session management.
- **Optimization:** Middleware-based validation and centralized error handling.

---

## Slide 8: Future Roadmap
- **AI Integration:** Predictive modeling for student success and personalized learning paths.
- **Real-time Engine:** WebSocket integration for instant notifications.
- **Mobile Ecosystem:** Dedicated Flutter or React Native apps for on-the-go access.
- **Advanced Reporting:** Auto-generated PDF report cards and analytics for parents.

---

## Slide 9: Conclusion
- **NavKalpana** is more than just a dashboard; it's a step towards data-driven education.
- **Impact:** Reduces administrative overhead by 40% and increases transparency for students.
